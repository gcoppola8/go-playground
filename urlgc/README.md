# URLGC — Go URL Shortener with Embedded Vite SPA

A self-contained MVC-ish URL shortener in Go. The backend exposes:
- POST `/api/urls` — create a short URL for a given target
- GET `/:code` — redirect to the original target if found, otherwise show a 404 page
- GET `/app` — serves the Single Page Application (SPA) built with Vite + TypeScript

The SPA is embedded into the Go binary using `go:embed`, so you can ship a single executable once you build the frontend.

## Backend — Run (Dev)

1. Ensure you have Go 1.22+ installed.
2. From the project root:

```
go run .
```

Server starts on `http://localhost:8080` by default.

- App UI: `http://localhost:8080/app`
- API health: `http://localhost:8080/api/health`

Environment variables:
- `PORT` — server port (default `8080`)
- `BASE_URL` — the public base URL used to construct returned short links (default `http://localhost:8080`)

## Frontend — Dev mode

The Vite dev server proxies `/api` to the Go server.

```
cd web/spa
npm install
npm run dev
```

Open the dev UI at the URL shown by Vite (usually `http://localhost:5173/app/`).

## Frontend — Build for embedding

To embed the SPA into the Go binary, build it so the output appears in `web/dist` (which is what `go:embed` includes):

```
cd web/spa
npm install
npm run build
```

After building, restart the Go server. The SPA will be served from `/app` directly by the Go binary (no Node server needed).

## API

- Create short URL
  - Request: `POST /api/urls`
  - Body JSON: `{ "target": "https://example.com" }` (scheme will default to `https://` if omitted)
  - Response JSON: `{ "code": "Ab12Cd34", "shortUrl": "http://localhost:8080/Ab12Cd34", "target": "https://example.com" }`

- Resolve short URL
  - Request: `GET /:code` (e.g., `/Ab12Cd34`)
  - Behavior: 302 redirect to the target if found; otherwise returns a minimal 404 HTML page.

## Notes

- Storage is in-memory for simplicity. Restarting the server clears mappings. You can later swap `Store` with a persistent backend.
- Short codes are 8 characters from `[a-zA-Z0-9]`.
- The SPA is intentionally minimal and framework-free (just TypeScript + Vite) to keep it lightweight.
